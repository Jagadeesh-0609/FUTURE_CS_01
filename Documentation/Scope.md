# Assessment Scope

- **Project:** Future Interns – Cyber Security Task 1 (2026)
- **Target URL:** http://testasp.vulnweb.com
- **Assessment Type:** Read-only Vulnerability Assessment & Configuration Review
- **Testing Approach:** Passive Analysis Only

## In-Scope Activities
- Publicly accessible page inspection via browser.
- Inspection of HTTP response headers and cookie configurations.
- Passive vulnerability analysis via OWASP ZAP (no active attacks, fuzzing, or automated exploits).
- Web configuration analysis (TLS enforcement, MIME sniffing, clickjacking protection).

## Out-of-Scope Activities
- Active exploitation, credential testing, or payload injections (SQLi, XSS, etc.).
- Authentication bypass or brute-force attempts.
- Denial of Service (DoS/DDoS) testing.
- Automated invasive fuzzing or unauthorized deep port scanning.
